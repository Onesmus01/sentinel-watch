# Sentinel Watch

A hazard monitoring dashboard. It should have a heading, verticall navbar aligned to the left, a mapframe at the center, with key containing coolor classes, and a footer. The navbar should carry search bars for location, county, sub county, and wards. below it, a Hazards' list ie. Flood, Drought, an d landslides. Below that should be a parameters' list ie. Gradient, rainfall, Temprature, and Humidity.  A user can choose to adjust the parameters or use the systems defaults. There should be a 'Run' button that when pressed directs the system to do the calculations and render the result on the map. Include a Download Reports page which a user can request for. Keep it intuitive, responsive and dynamic while still caring for proffesionalism and user friendliness.
